# 고정 목표 이미지 선택 흐름

새 세션 → 모델 선택(Gemini 기본 선택, 준비 상태 확인) → 목표 이미지 선택 → 세션 저장 → 채팅.

- `web/src/data/challengeTargets.ts`: 9개 목표 ID·제목·테마·난이도·힌트.
- `web/public/challenge-targets/`: 선택한 원본 PNG. B중·상은 모자·멜빵바지가 없는 목표.
- `web/public/challenge-targets/sources.json`: 제작 환경에서 확정한 원본 이미지 출처.
- `TargetImagePicker`: 1단계 모델 팝업, 2단계 A/B/C × 하/중/상 선택 팝업. 이미지 클릭으로 생성 시작.
- `TargetImagePanel`: 선택 목표 이름과 접을 수 있는 힌트 그룹(그림체 / 캐릭터·물건·행동 / 배경·구도).

선택 이미지를 data URL로 읽고 기존 `POST /api/challenges`에 `target_image`, 선택한 `profile_id`를 보낸다. 따라서 선택한 이미지 원본은 기존 Supabase Storage 저장 경로를 사용하며 서버·SQL·환경변수 변경은 필요 없다. 목표 ID와 힌트 연결은 현재 브라우저 세션의 Challenge에 유지된다. 새로고침 후 세션 목록 복구는 기존과 동일하게 이번 범위에 포함하지 않는다.

파일 업로드 입력은 고정 이미지 선택 UI로 대체했다. 이미지를 바꾸려면 새 세션에서 모델·이미지를 다시 고른다. 저장 중 중복 선택과 모달 닫기를 막고, 실패 시 오류를 표시하고 다시 선택할 수 있다. 준비되지 않은 GPU 프로필은 선택할 수 없다.

## 힌트 선정 기준

목표에 실제로 보이는 대상·물건·행동·배경을 단어/짧은 구문으로 제공한다. 생성 테스트에서 나타난 실패를 정답으로 반영하지 않는다. B에 모자·멜빵바지를 넣지 않고 C에 앞발 자세·아이싱·개수 지시를 넣지 않는다. 스타일·내용·구도별로 나눠 직접 프롬프트에 활용할 수 있게 한다.

| 목표 | 주요 키워드 |
|---|---|
| A하 | 픽셀아트, 주황 아기 다람쥐, 초록 뚜껑·크림색 컵, 정면, 크림색 배경 |
| A중 | 같은 다람쥐·컵, 컵을 입에 대고 마시기, 가을 숲, 나무다리 |
| A상 | 같은 컵, 왼쪽 다람쥐·오른쪽 흰 토끼, 컵 건네고 받기, 가을 숲 나무다리 |
| B하 | 동화책 그림체, 주황 아기 여우, 은색 물뿌리개 들기, 정면, 크림색 배경 |
| B중 | 여우 한 마리, 은색 물뿌리개를 기울여 새싹에 물 주기, 도시 노을, 옥상 텃밭 |
| B상 | 왼쪽 여우 물 주기·오른쪽 흰 토끼 삽질, 은색 물뿌리개, 작은 삽, 같은 옥상·도시·노을 |
| C하 | 부드러운 3D, 회색·흰색 아기 고양이, 분홍색 도넛, 앉기, 연분홍 배경 |
| C중 | 같은 고양이·도넛, 오른쪽으로 수평 비행, 파란 하늘, 구름, 무지개 |
| C상 | 왼쪽 고양이·도넛, 오른쪽 흰 토끼, 공중에서 마주 보기, 같은 하늘·구름·무지개 |

## 확인

`web`에서 `npm ci` 후 `npm run build`.

빌드 통과. 9개 ID·테마별 하중상 순서, 원본 PNG와 API에 보내는 data URL 바이트 일치, B 힌트의 복장 문구 제거, 이미지 로드 실패 처리를 코드 실행으로 확인했다. 운영 서버에 실제 세션을 만들거나 유료 모델 호출은 하지 않았다.
