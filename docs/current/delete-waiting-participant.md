# Bike 대기 참가자 삭제

대기 참가자 카드 오른쪽 × → 삭제 확인을 누르면 해당 참가자의 다음 데이터를 함께 삭제한다.

- 대기 항목, PASS 영수증, 챌린지 세션, 프롬프트/시도, 생성·판정 호출 원장.
- 연결된 목표/성공 이미지: Storage API로 삭제한다. 오류가 나면 기존 삭제 대기열에서 재시도한다.
- Mac의 대기 목록 캐시·선택·시작 요청 ID도 정리한다.

계측을 시작했거나 이미 계측/인쇄 기록이 있는 참가자는 삭제하지 않는다.
다른 측정소 참가자는 삭제할 수 없으며, 오프라인에서 삭제를 확인할 수 없으면 목록을 유지한다.
이 기능은 운영자가 명시적으로 지우는 기능이므로 자동 정리와 달리 선택한 PASS 기록도 삭제한다.

## 적용

1. 기존 자동 정리 SQL 이후 아래 파일 전체를 Supabase SQL Editor에서 한 번 실행한다.
   `supabase/migrations/202611040003_delete_waiting_participant.sql`
2. Render에 새 main 코드를 배포한다. 추가 환경변수는 없다.
3. 진행 중인 계측이 없는 상태에서 Mac Bike 서버를 Ctrl+C로 종료하고 같은 명령으로 다시 실행한다.
4. Bike 페이지를 새로고침한다. 프린터·Vercel 프런트 재설정은 필요 없다.

실제 대기 참가자는 이 구현 중 삭제하지 않았다. 화면 점검은 사용자 요청에 따라 생략한다.
