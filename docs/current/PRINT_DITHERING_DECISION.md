# PT-210 · Atkinson 선택 기록

정리: 2026-11-13. GitHub 1a306e7의 최신 코드/운영 문서·보관 비교 시안·2026-11-01 설치 기록을 대조했다. 당시 선택 사유를 기록한 별도 회의록이나 실물 평가표는 발견되지 않았다. 따라서 아래 시안 관찰과 구현상의 근거는 지금 복원한 설명이며, 당시 사용자의 실물 평가 발언을 재현한 기록은 아니다.

## 요구 조건

- PT-210, 58mm 용지에서 실제 인쇄 폭 384dots. 초기 비교 사진은 좌우 여백을 제외한 360dots. 최신 최종 영수증의 사진 폭은 232dots이며 비교 시트와 구분한다.
- 컬러 사진을 흑백 1bit 비트맵으로 변환. 한글·숫자·QR/텍스트는 별도로 선명하게 렌더링.
- 최종 인쇄 크기로 먼저 리사이즈한 뒤 디더링. 만들어진 도트 패턴을 다시 확대·축소하지 않음.
- 원본 및 DB 성공 이미지는 유지. 출력용 사본만 변환하며 모델 API를 추가 호출하지 않음.

## 비교 과정

1. 같은 원본 사진을 360dots, 밝기 1.0·대비 1.0으로 맞췄다.
2. 브라우저 실사용 `web/src/utils/thermal.ts`로 네 알고리즘을 각각 독립 적용했다.
3. 비교 시트와 ESC/POS 데이터를 만들고 비교 출력 작업을 1회 제출했다.
4. 이후 Atkinson을 적용한 최종 영수증 레이아웃을 준비·제출했고, 브라우저 기본값과 워커 렌더러에 Atkinson을 사용했다.

준비 도구: `printer_bridge/dither_test.cjs`, `printer_bridge/prepare_test.py`.
로컬 비교 시트: `output/pt210-test/02-dither-comparison.png`.
최종 시안: `output/pt210-test/04-final-atkinson.png`.
출력물에는 참가자 사진·프롬프트가 포함될 수 있어 Git 공개 자료로 복사하지 않는다.

## 보관된 디지털 시안에서 확인한 차이

| 방식 | 같은 사진에서 관찰한 표현 |
| --- | --- |
| Atkinson | 밝은 배경의 흰 영역이 넓고 비행기 윤곽과 어두운 부분이 강하게 구분됨. 중간 명암의 일부는 줄어듦 |
| Floyd–Steinberg | 중간 명암이 점으로 더 많이 이어지고 배경에도 도트가 남음 |
| Ordered Bayer | 규칙적인 격자 패턴이 사진 전반에서 눈에 띔 |
| Ordered Blue Noise | 규칙 격자 대신 분산된 입자감으로 중간 명암을 표현함 |

이는 저장된 PNG 한 장의 육안 관찰이다. 종이·열 농도·드라이버에 따른 출력 품질 순위를 뜻하지 않는다.

## 현재 선택을 설명하는 근거

흰 배경과 주 피사체의 윤곽을 분리해 좁은 영수증에서도 사진 내용을 읽게 하는 목적에 Atkinson 기본값이 부합한다. 중간 명암 재현을 최대로 유지하는 목적과는 절충이 있다. 소스의 Atkinson 커널은 오차를 6개 이웃에 각각 1/8만 전달하며 총 6/8을 확산한다. Floyd–Steinberg는 7/16·3/16·5/16·1/16으로 오차를 확산한다. 이 구현 차이와 실제 시안의 표현 차이를 함께 기록한다.

브라우저는 네 방식을 선택할 수 있고 워커는 Atkinson으로 고정돼 있다. 한 사진에서의 선택을 모든 사진·프린터에 대한 우수성으로 일반화하지 않는다.

## 확인된 것과 남은 것

- 설치 기록에 초기 연결·한글/QR 인쇄 성공의 사용자 확인이 있다.
- 초기 설치 기록의 4방식 비교 출력·최종 시안 확인은 당시 대기로 남아 있다. 이후 최신 운영 문서에는 캠페인과 PT-210 실물 출력 완료가 운영자 확인으로 기록돼 있다. 따라서 최종 출력 전체를 미확인 상태로 되돌리지 않는다. 네 방식별 실물 비교 평가표는 여전히 발견되지 않았다.
- 현재 브라우저 기본값: `web/src/components/Receipt.tsx`.
- 최신 GitHub 워커 변환: `printer_bridge/renderer.py`.
- 커널 일치 확인: `printer_bridge/test_worker.py`와 `web/scripts/test-thermal.cjs`.
- 프린터 드라이버 설치 출처·라이선스: [설치 기록](../../printer_bridge/setup/README.md).

추후 알고리즘별 실물 비교 평가를 추가하면 종이·농도·가독성 조건과 함께 이 문서를 갱신한다. 이번 작업은 실제 인쇄나 원격 배포를 실행하지 않았다.

## 초기 비교와 최종 운영 구분

초기 360dots 비교 시트는 알고리즘 선택 과정을 설명하는 자료다. 최신 최종 출력은 384dots 용지에 232dots 사진을 중앙 배치하고, 자전거 체험 종료 후 인쇄한다. 최신 행사 운영·모델·출력 내용은 [운영 기준](OPERATIONS.md)을 따른다.
